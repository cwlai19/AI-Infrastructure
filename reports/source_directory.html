Search from the tracker

Sources marked live search are queried directly by the tracker. One command runs every live source for a jurisdiction and prints lookup links for the rest. Jurisdictions take codes or names (uk, lux, ie, nl, de, fr, es, it, no, se, dk, fi, eu, us) and can be combined with commas.

python -m tracker search uk,lu "Nscale"
python -m tracker sources lu --paid
